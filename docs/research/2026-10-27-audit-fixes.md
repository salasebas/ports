## Implementation choices

The Engine transport follows [reqwest's Unix-socket client support](https://docs.rs/reqwest/0.13.5/reqwest/blocking/struct.ClientBuilder.html#method.unix_socket). Version 0.13.5 was already transitive; this change enables its blocking client directly and adds no second HTTP implementation.

Shared process groups cannot safely receive group-wide signals because they may include Ports or unrelated applications. The shared-group fallback intentionally uses SIGSTOP followed by SIGKILL on the selected tree, rather than running shutdown handlers that can fork and immediately reparent children. Isolated job groups retain the TERM grace period and KILL escalation. A process deliberately escaping observation by daemonizing or changing identity remains subject to operating-system inspection races; these tests cover ordinary server trees and the reproduced shutdown-handler cases.

Framework detection is deliberately conservative when the only evidence is an installed dependency. Project identification still works; an unknown custom listener receives a TCP probe. No Swift integration, restart redesign, additional runtime, or feature-list item is introduced.

## Validation

- Linux: full native Rust tests, Clippy for all targets with warnings denied, Rust formatting, Svelte/TypeScript checking, frontend tests, lint, formatting, and production frontend build.
- Permanent suites: 72 Rust tests and 54 frontend tests after this repair pass.
- Fresh-context independent reviews validated backend ownership/shutdown and frontend/settings/concurrency. Their confirmed findings were reproduced and corrected before PR creation.
- Svelte analyzer checked the modified components/modules. Its local-Map suggestion concerns a fresh map inside a derived calculation; it does not hold reactive state. Its layout navigation warning does not recognize the `resolve("/")` call inside the URL template. Type checks and production build validate that route.
- macOS execution, native shortcut/window interaction, and long-running memory profiling were not performed in this Linux environment. CI runs the native suite on both Linux and macOS; its result is reported with the PR.
